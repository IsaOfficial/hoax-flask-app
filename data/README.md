Daftar `stopwords_indonesian.txt` disalin dari korpus stopwords NLTK
(758 baris), diambil pada 6 September 2026 dari:
https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/corpora/stopwords.zip

README korpus asli disertakan sebagai `stopwords_README.txt`.
Daftar ini disimpan bersama aplikasi agar preprocessing konsisten dan tidak
memerlukan akses jaringan saat startup. Urutan preprocessing mengikuti
`model_pipeline.py` yang tersedia; kode pelatihan asli tidak disertakan di repositori.
